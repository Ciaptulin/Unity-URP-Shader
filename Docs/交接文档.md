## 一、项目是什么

一个**边学边做**的 Unity URP 自定义 PBR shader 项目。

- **目标**：跟随 `Docs/` 下的教程，从零手写 `Custom/MyLit`
- **环境**：Unity 2023.2.20f1 + URP 16.0.6
- **仓库**：`git@github.com:Ciaptulin/Unity-URP-Shader.git`

**和普通项目不同**：这里代码是**学习成果**，注释、锚点、文档的价值不低于代码本身。

## 四、代码约定（重要）

### 格式

- **大括号换行**（K&R 的变体）：
  ```hlsl
  struct Interpolators
  {
      ...
  };
  ```
- **顶点输出结构体统一叫 `Interpolators`**（不用 `Varyings`）
- **局部变量统一 `posInputs` / `normInputs`**
- **注释 `// ` 后带空格**

### 锚点

每个逻辑块前用统一标记标记来源章节：

```hlsl
// ===== [Part5-七] 深度 + 法线通道（SSAO / SSR 用）=====
```

### 调试片段

调试用的 `return` 不留在主逻辑里，集中到文件底部：

```hlsl
// ==================== 调试片段（需要时临时挪到 Fragment 里）====================
// uv 可视化：      return float4(uv, 0, 1);
// ==========================================================================
```

### 注释语言

中英混合：术语保留英文（TBN、NDC、SRP Batcher），解释用中文。

## 六、教学方式（重要）

这个项目的学习方式是**"讲解 + 考题 + 错题复盘"**：

1. **讲解**：先讲原理，再给代码
2. **考题**：每讲完一块出题验证，答完批改
3. **错题**：错的地方重点纠正，记入 `Part5-七-学习笔记.md` 的错题本
4. **偏题提醒**：学习者有时答题偏题，需要**明确划边界**

**已发现的学习者薄弱点**（如果继续教学，重点关注）：

| 薄弱点 | 表现 |
|---|---|
| 空间概念（相机 vs 物体）| "世界空间 TBN 与相机无关"反复错 |
| 数 token 默认项 | `multi_compile _ _A _B` 数成 2 份（正确 3 份）|
| 优化维度单一 | 只想到"改 pragma"，忘了"Variant Stripping" |
| 答题偏题 | 引入题目没问的相关概念 |
