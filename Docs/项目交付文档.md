## 1. 项目概述

一个基于 Unity URP 的自定义 PBR 着色器 `MyLit`，实现了程序化点阵镂空（Dot Matrix Hatching）效果。配套完整的中文着色器教程（Part 1-9 + 反射探针示例）。

### 核心特性

- PBR 物理光照模型（`UniversalFragmentPBR`）
- 双工作流（金属度 / 镜面反射）
- 法线贴图、粗糙度贴图、自发光、视差、遮挡贴图、清漆
- 程序化点阵镂空（半色调 halftone）
- 多种表面类型（Opaque / Cutout / TransparentBlend）
- 面渲染模式（FrontOnly / NoCulling / DoubleSided）
- 完整 URP 光照接入（附加光源、反射探针、烘焙 GI、SSO、光源层级）
- 5 个 Shader Pass（ForwardLit / ShadowCaster / DepthOnly / DepthNormals / Meta）
- 自定义材质 Inspector

## 3. 代码架构

### 3.1 Shader 核心文件

#### `MyLit.shader`
- 材质属性声明（Properties）
- 5 个 Pass 定义（ForwardLit / ShadowCaster / DepthOnly / DepthNormals / Meta）
- Shader Variant 关键字声明
- 默认 blend/ZWrite 值：`_SourceBlend=1, _DestBlend=0, _ZWrite=1`

#### `MyLitCommon.hlsl`
- `CBUFFER_START(UnityPerMaterial)` 包裹所有材质属性（SRP Batcher 兼容）
- `TEXTURE2D` 声明所有纹理
- `TestAlphaClip()` — Alpha 裁切函数
- `CalculateDotMatrix()` — 点阵镂空（UV 版 + 世界坐标版）

#### `MyLitForwardLitPass.hlsl`
- `Attributes` / `Interpolators` 结构体
- `Vertex()` — 顶点函数（含光照贴图 UV 传递）
- `Fragment()` — 片元函数（PBR 光照 + 法线 + 视差 + 清漆 + 遮挡 + 点阵）
- 最后一行：`return UniversalFragmentPBR(lightingInput, surfaceInput);`

#### 其他 Pass
- `MyLitShadowCasterPass.hlsl` — 阴影投射，支持 Alpha 裁切镂空
- `MyLitDepthOnlyPass.hlsl` — 仅深度，支持 Alpha 裁切
- `MyLitDepthNormalsPass.hlsl` — 深度+法线，支持法线贴图
- `MyLitMetaPass.hlsl` — 光照烘焙元通道

### 3.2 C# 脚本

| 文件 | 功能 |
|------|------|
| `MyLitCustomInspector.cs` | 材质 Inspector，管理 SurfaceType / BlendType / FaceRenderingMode 下拉菜单，自动同步 Blend / ZWrite / Cull / Shader Keywords |
| `AdditionalLightShadowController.cs` | 编辑器中配置附加光源阴影（Soft/Hard/None） |

## 8. 常见调试方法

| 问题 | 排查方式 |
|------|----------|
| 材质全黑 | 检查 `SurfaceData` 字段是否完整；确认场景有反射探针或天空盒 |
| SSAO 不生效 | 检查 `lightingInput.normalizedScreenSpaceUV` 是否赋值 |
| 影子静止 | ShadowCaster Pass 是否同步了顶点动画 |
| 烘焙 GI 异常 | 用 `_DEBUG_BAKED_GI` 关键字输出灰度图 |
| 变体被剥离 | 确保至少一个材质预启用该关键字，或用 `ShaderVariantCollection` |
| SRP Batcher 不工作 | 检查 CBUFFER 一致性；确认没使用 MPB |

## 10. 关键约定

1. **所有材质属性必须放进 `UnityPerMaterial` CBUFFER**（SRP Batcher 要求）
2. **切线数据始终传递**，不依赖 `_NORMALMAP` 关键字
3. **视差始终执行**，不依赖 `_NORMALMAP` 关键字
4. **全局属性不加 `MyGame_` 前缀**（避免命名冲突）
5. **关键字用 `shader_feature_local`，全局控制用 `multi_compile`**
