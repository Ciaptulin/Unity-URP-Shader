## 顶点着色器基础

到目前为止，我们的顶点函数只做了最基本的变换：将对象空间位置转换到裁剪空间。现在，我们要在变换**之前**修改顶点位置。

### 对象空间 vs 世界空间

一个关键问题：你应该在哪个空间做顶点动画？

| 空间 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **对象空间** | 简单、可预测 | 不考虑对象旋转 | 旗帜、局部摆动 |
| **世界空间** | 考虑全局位置 | 需要额外变换 | 风、水流 |
| **切线空间** | 沿表面方向 | 需要切线数据 | 表面涟漪 |

### 修改顶点位置

基本模式是：

```hlsl
Interpolators Vertex(Attributes input)
{
    Interpolators output = (Interpolators)0;
    
    // 1. 获取对象空间位置
    float3 positionOS = input.positionOS.xyz;
    
    // 2. 修改位置（动画逻辑在这里）
    positionOS.y += sin(_Time.y * 2) * 0.1;
    
    // 3. 标准变换
    output.positionWS = TransformObjectToWorld(positionOS);
    output.positionCS = TransformWorldToHClip(output.positionWS);
    
    // 4. 传递其他数据
    output.normalWS = TransformObjectToWorldNormal(input.normalOS);
    output.uv = TRANSFORM_TEX(input.uv, _ColorMap);
    
    return output;
}
```

> **重要：** 始终在变换**之前**修改对象空间位置。如果你在世界空间中修改，然后变换到裁剪空间，结果会因为对象的旋转和缩放而出错。

## 正弦波动画

### 基础波浪

最简单的顶点动画——沿 Y 轴的正弦波：

```hlsl
// 属性
_WaveFrequency("Wave Frequency", Float) = 1
_WaveAmplitude("Wave Amplitude", Float) = 0.1
_WaveSpeed("Wave Speed", Float) = 1

// HLSL
float _WaveFrequency;
float _WaveAmplitude;
float _WaveSpeed;

// 在 Vertex 函数中
float wave = sin(_Time.y * _WaveSpeed + positionOS.x * _WaveFrequency);
positionOS.y += wave * _WaveAmplitude;
```

### 多频率叠加

单层正弦波看起来很假。叠加多个频率来创建更自然的运动：

```hlsl
float wave1 = sin(_Time.y * 1.0 + positionOS.x * 2.0) * 0.05;
float wave2 = sin(_Time.y * 2.3 + positionOS.z * 3.1) * 0.03;
float wave3 = sin(_Time.y * 0.7 + positionOS.x * 1.5 + positionOS.z * 0.8) * 0.04;

positionOS.y += wave1 + wave2 + wave3;
```

> **技巧：** 使用不同的频率和相位偏移来打破规律性。这叫做**分形噪声（Fractal Noise）** 的简化版。

## 风效模拟

### 方向性风

对于草和植物，我们想要沿风向的摆动，根部固定，顶部摆动幅度最大：

```hlsl
// 属性
_WindDirection("Wind Direction", Vector) = (1, 0, 0, 0)
_WindStrength("Wind Strength", Float) = 0.1
_WindSpeed("Wind Speed", Float) = 1.0
_WindFrequency("Wind Frequency", Float) = 0.5

// HLSL
float3 _WindDirection;
float  _WindStrength;
float  _WindSpeed;
float  _WindFrequency;

// 在 Vertex 函数中
// 根据顶点高度计算影响（根部不动）
float heightFactor = saturate(positionOS.y / _MaxHeight);

// 世界空间位置用于风的计算
float3 positionWS = TransformObjectToWorld(positionOS);

// 风向点积 + 时间 = 风相位
float windPhase = dot(positionWS.xz, _WindDirection.xz) * _WindFrequency;
float windWave = sin(_Time.y * _WindSpeed + windPhase);

// 应用风偏移
float3 windOffset = _WindDirection.xyz * windWave * _WindStrength * heightFactor;
positionWS += windOffset;

// 转回对象空间（如果需要）或直接用世界空间
// 方案 A：继续用世界空间
output.positionWS = positionWS;
output.positionCS = TransformWorldToHClip(positionWS);
```

### 每实例随机种子

如果你有一片草地，所有草同步摆动看起来很假。给每个实例一个随机相位：

```hlsl
// 使用实例 ID 作为随机种子
float randomSeed = input.instanceID * 12.9898;
float randomPhase = sin(randomSeed) * 6.28318;  // [0, 2π]

float windWave = sin(_Time.y * _WindSpeed + windPhase + randomPhase);
```

### 噪声风

对于更有机的风效，使用噪声函数：

```hlsl
// 简单的 2D 噪声（基于正弦）
float Noise2D(float2 p)
{
    return sin(p.x) * cos(p.y) * 0.5 + 0.5;
}

// 在顶点函数中
float2 noiseUV = positionWS.xz * 0.1 + _Time.y * 0.1;
float noise = Noise2D(noiseUV);
float windWave = sin(_Time.y * _WindSpeed + noise * 6.28);
```

## 旗帜动画

### 正弦旗帜

经典的旗帜飘动——沿旗杆固定，旗尾大幅摆动：

```hlsl
// 属性
_FlagWaveStrength("Wave Strength", Float) = 0.3
_FlagWaveFrequency("Wave Frequency", Float) = 3.0
_FlagWaveSpeed("Wave Speed", Float) = 2.0
_FlagPoleAxis("Pole Axis", Vector) = (1, 0, 0, 0)

// HLSL
float _FlagWaveStrength;
float _FlagWaveFrequency;
float _FlagWaveSpeed;
float3 _FlagPoleAxis;

// 在 Vertex 函数中
// 计算顶点到旗杆轴的距离
float distanceFromPole = length(positionOS.xyz - _FlagPoleAxis.xyz * positionOS.x);

// 距离越远，摆动越大
float waveFactor = saturate(distanceFromPole / _FlagWidth);

// 正弦波沿旗帜表面传播
float wave = sin(_Time.y * _FlagWaveSpeed - positionOS.x * _FlagWaveFrequency);

// 主要摆动沿 Z 轴（旗帜的法线方向）
positionOS.z += wave * _FlagWaveStrength * waveFactor;

// 次要摆动沿 Y 轴（轻微上下）
positionOS.y += wave * _FlagWaveStrength * 0.3 * waveFactor;
```

### 基于曲线的旗帜

使用 `_Time` 驱动一个更简单的波形：

```hlsl
// 简单的渐进波形
float wave = sin(_Time.y * _FlagWaveSpeed) * 0.5 
         + sin(_Time.y * _FlagWaveSpeed * 0.7 + 1.3) * 0.3
         + sin(_Time.y * _FlagWaveSpeed * 1.3 + 2.1) * 0.2;

positionOS.z += wave * _FlagWaveStrength * waveFactor;
```

## 顶点颜色遮罩

**顶点颜色**是控制每个顶点受影响程度的完美方式。在建模软件中（如 Blender），你可以绘制顶点颜色来标记哪些部分应该摆动。

```hlsl
// 在 Attributes 中添加
float4 color : COLOR;

// 在 Interpolators 中传递
float4 vertexColor : COLOR;

// 在 Vertex 函数中
output.vertexColor = input.color;

// 使用红色通道作为影响因子
float influence = input.color.r;

// 应用到风效
float3 windOffset = _WindDirection.xyz * windWave * _WindStrength * influence;
```

> **用例：** 草的尖端白色（全影响），根部黑色（无影响）。旗帜的旗杆边红色为 0，旗尾红色为 1。

## 骨骼式顶点动画

### 时间偏移

模拟骨骼链的简单方法——每个"骨骼"有不同的相位偏移：

```hlsl
// 属性
_BoneCount("Bone Count", Float) = 4
_BoneAmplitude("Bone Amplitude", Float) = 0.1
_BoneSpeed("Bone Speed", Float) = 1.0

// HLSL
float _BoneCount;
float _BoneAmplitude;
float _BoneSpeed;

// 在 Vertex 函数中
// 假设 Y 轴是骨骼链方向
float boneIndex = floor(positionOS.y / _BoneHeight);
float phaseOffset = boneIndex * 0.5;  // 每个骨骼相位差

float boneWave = sin(_Time.y * _BoneSpeed - phaseOffset);
float2 boneDir = normalize(float2(positionOS.x, positionOS.z));

positionOS.xz += boneDir * boneWave * _BoneAmplitude * (boneIndex / _BoneCount);
```

### 程序化骨骼

对于更可控的骨骼动画，在 C# 中计算骨骼变换矩阵，传递给着色器：

```csharp
// C# 脚本
public class BoneAnimator : MonoBehaviour
{
    public Material targetMaterial;
    public int boneCount = 4;
    
    private Matrix4x4[] boneMatrices;
    
    void Update()
    {
        for (int i = 0; i < boneCount; i++)
        {
            float phase = Time.time * speed - i * 0.5f;
            float angle = Mathf.Sin(phase) * maxAngle;
            
            Matrix4x4 mat = Matrix4x4.TRS(
                Vector3.zero,
                Quaternion.Euler(0, 0, angle),
                Vector3.one
            );
            
            targetMaterial.SetMatrix($"_BoneMatrix{i}", mat);
        }
    }
}
```

```hlsl
// HLSL —— 每个骨骼一个矩阵
#define MAX_BONES 8
float4x4 _BoneMatrix[MAX_BONES];
float _BoneHeight;
float _BoneCount;

// 在 Vertex 函数中
float boneIndex = floor(positionOS.y / _BoneHeight);
boneIndex = clamp(boneIndex, 0, _BoneCount - 1);

// 从对象空间中心偏移
float3 pivot = float3(0, boneIndex * _BoneHeight, 0);
float3 localPos = positionOS - pivot;

// 应用骨骼旋转
float4x4 boneMat = _BoneMatrix[boneIndex];
float3 rotatedPos = mul(boneMat, float4(localPos, 1)).xyz;

positionOS = rotatedPos + pivot;
```

## 交互式顶点位移

### 点击涟漪

当玩家点击表面时，创建涟漪效果：

```csharp
// C# —— 发送点击位置到着色器
public class RippleSender : MonoBehaviour
{
    public Material targetMaterial;
    
    void Update()
    {
        if (Input.GetMouseButtonDown(0))
        {
            Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
            if (Physics.Raycast(ray, out RaycastHit hit))
            {
                targetMaterial.SetVector("_RippleOrigin", hit.point);
                targetMaterial.SetFloat("_RippleTime", Time.time);
            }
        }
    }
}
```

```hlsl
// HLSL
float3 _RippleOrigin;
float  _RippleTime;
float  _RippleSpeed = 2.0;
float  _RippleAmplitude = 0.1;
float  _RippleWidth = 0.5;

// 在 Vertex 函数中
float3 positionWS = TransformObjectToWorld(positionOS);
float distToRipple = distance(positionWS.xz, _RippleOrigin.xz);

// 涟漪从原点向外传播
float rippleAge = _Time.y - _RippleTime;
float rippleRadius = rippleAge * _RippleSpeed;
float rippleDist = abs(distToRipple - rippleRadius);

// 高斯衰减的涟漪
float ripple = exp(-rippleDist * rippleDist / _RippleWidth) 
              * sin(distToRipple * 10 - rippleAge * _RippleSpeed * 5);

positionWS.y += ripple * _RippleAmplitude;
```

### 角色踩踏

草被角色踩踏的效果：

```csharp
// C# —— 在角色脚下发送位置
public class GrassStomper : MonoBehaviour
{
    public Material grassMaterial;
    public float stompRadius = 2f;
    public float stompDepth = 0.3f;
    
    void Update()
    {
        grassMaterial.SetVector("_StompPosition", transform.position);
        grassMaterial.SetFloat("_StompRadius", stompRadius);
        grassMaterial.SetFloat("_StompDepth", stompDepth);
    }
}
```

```hlsl
// HLSL
float3 _StompPosition;
float  _StompRadius;
float  _StompDepth;

// 在 Vertex 函数中
float3 positionWS = TransformObjectToWorld(positionOS);
float distToStomp = distance(positionWS.xz, _StompPosition.xz);

// 平滑衰减
float stompFactor = 1 - smoothstep(0, _StompRadius, distToStomp);
stompFactor = pow(stompFactor, 2);  // 更尖锐的衰减

// 向下弯曲
float3 stompDir = normalize(positionWS.xz - _StompPosition.xz);
positionWS.xz += stompDir * stompFactor * _StompDepth;
positionWS.y -= stompFactor * _StompDepth * 0.5;
```

## 运动矢量（Motion Vectors）

当你在 URP 中使用顶点动画时，**运动矢量**变得很重要——它们让后期效果（如运动模糊和时域抗锯齿）知道像素移动了多远。

### 设置运动矢量 Pass

URP 提供了内置的运动矢量支持。在 `MyLit.shader` 中添加一个 Pass：

```hlsl
Pass
{
    Name "MotionVectors"
    Tags { "LightMode" = "MotionVectors" }
    
    HLSLPROGRAM
    #pragma vertex MotionVectorVertex
    #pragma fragment MotionVectorFragment
    
    #include "Packages/com.unity.render-pipelines.universal/Shaders/MotionVectorCommon.hlsl"
    #include "MyLitMotionVectorPass.hlsl"
    ENDHLSL
}
```

创建 `MyLitMotionVectorPass.hlsl`：

```hlsl
#ifndef MY_LIT_MOTION_VECTOR_PASS_INCLUDED
#define MY_LIT_MOTION_VECTOR_PASS_INCLUDED

#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

// 包含你的顶点动画函数
#include "MyLitVertexAnimation.hlsl"

struct MotionAttributes
{
    float4 positionOS : POSITION;
    float3 normalOS : NORMAL;
    #if defined(_ALPHATEST_ON)
        float2 uv : TEXCOORD0;
    #endif
    UNITY_VERTEX_INPUT_INSTANCE_ID
};

struct MotionVaryings
{
    float4 positionCS : SV_POSITION;
    float4 previousPositionCS : TEXCOORD0;
};

MotionVaryings MotionVectorVertex(MotionAttributes input)
{
    MotionVaryings output = (MotionVaryings)0;
    UNITY_SETUP_INSTANCE_ID(input);
    
    // 当前帧位置（带动画）
    float3 positionOS = input.positionOS.xyz;
    ApplyVertexAnimation(positionOS);  // 你的动画函数
    
    output.positionCS = TransformObjectToHClip(positionOS);
    
    // 上一帧位置（用上一帧的时间）
    float3 prevPositionOS = input.positionOS.xyz;
    ApplyVertexAnimation(prevPositionOS, _Time.y - unity_DeltaTime.x);
    
    float4x4 prevM = unity_MatrixPreviousM;
    float4 prevClipPos = mul(prevM, float4(prevPositionOS, 1));
    output.previousPositionCS = mul(UNITY_MATRIX_P, prevClipPos);
    
    return output;
}

half4 MotionVectorFragment(MotionVaryings input) : SV_TARGET
{
    // URP 内置函数计算运动矢量
    return float4(CalculateMotionVector(input.positionCS, input.previousPositionCS), 0, 1);
}

#endif
```

> **关键：** 运动矢量 Pass 需要计算**当前帧**和**上一帧**的裁剪空间位置，然后计算它们之间的差值。

## 性能考量

### SRP Batcher 兼容性

顶点动画**不会**破坏 SRP Batcher——只要你遵循 CBUFFER 规则。但是：

- **GPU Instancing + 顶点动画：** 兼容，但每个实例需要独立的动画参数
- **静态批处理（Static Batching）：** ❌ 不兼容（静态批处理在 CPU 端合并网格，顶点着色器看不到原始对象空间）
- **动态批处理（Dynamic Batching）：** ❌ 不兼容（顶点数超过限制）

### 优化技巧

1. **在顶点着色器中做最少的工作：** 避免复杂的噪声函数
2. **预计算：** 在 C# 中计算复杂动画，通过材质属性传递结果
3. **LOD：** 远距离物体使用更简单的动画或完全禁用
4. **GPU Instancing：** 对于大量相似物体（草、树叶），使用实例化 + 每实例随机种子

### 顶点动画 vs 骨骼动画

| 特性 | 顶点动画 | 骨骼动画 |
|------|----------|----------|
| CPU 开销 | 极低 | 中等（蒙皮计算） |
| GPU 开销 | 低 | 中等（蒙皮矩阵） |
| 灵活性 | 程序化、无限变化 | 手动制作、精确控制 |
| 适用场景 | 草、旗帜、水、简单摆动 | 角色、复杂机械 |

## 总结

### 顶点动画速查表

| 效果 | 核心公式 | 复杂度 |
|------|---------|--------|
| **正弦波浪** | `sin(time * speed + pos * freq)` | ⭐ |
| **方向性风** | `windDir * sin(time + dot(pos, windDir))` | ⭐⭐ |
| **旗帜飘动** | `sin(time - x * freq) * distanceFromPole` | ⭐⭐ |
| **噪声风** | `sin(time + noise(pos * scale))` | ⭐⭐⭐ |
| **顶点颜色遮罩** | `vertexColor.r * animation` | ⭐ |
| **骨骼链** | 每骨骼相位偏移 + 旋转矩阵 | ⭐⭐⭐ |
| **点击涟漪** | `exp(-d²) * sin(dist * freq - time)` | ⭐⭐ |
| **踩踏弯曲** | `smoothstep(dist, radius) * direction` | ⭐⭐ |

### 关键提醒

- ✅ 始终在**对象空间**修改顶点，然后变换到世界/裁剪空间
- ✅ 使用顶点颜色或 UV 作为影响遮罩
- ✅ 为运动模糊/时域 AA 提供运动矢量 Pass
- ✅ 用 `saturate` 和 `smoothstep` 限制位移范围
- ❌ 不要在顶点着色器中做纹理采样（太昂贵）
- ❌ 不要对大量顶点做复杂数学运算
