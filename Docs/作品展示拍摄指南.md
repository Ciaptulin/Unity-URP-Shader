# MyLit 作品展示拍摄指南

> 目标：把 `Custom/MyLit` 的每个特性拍成"一眼能看懂"的展示图/短视频，用于 GitHub README、B站、社群招募。
> 核心原则：**参数动起来 > 角色动起来**。TA 展示的是材质和光照，不是动画。

---

## 一、开拍前的场景准备（一次性）

1. **环境光**：Window > Rendering > Lighting > Environment
   - Source 改为 `Skybox`，或指定一张 HDRI（Poly Haven 免费下载）
   - 这样反射探针有内容，金属球才不会是一坨灰
2. **灯光**：Directional Light（主光，开阴影）+ 一盏暖色 Point/Spot（补光）+ 一盏背后 rim 光打角色轮廓
3. **相机**：Main Camera，Clear Flags = Skybox，FOV 40-50
4. **窗口**：关掉 AI Navigation、Console、Scene 视图，只留 Game 视图最大化（减少出镜杂物）
5. **分辨率**：Game 视图切 `16:9`，或固定 1920x1080

## 二、每个特性拍什么（按卖点排序）

| # | 特性 | 拍摄对象 | 关键参数 | 拍摄方式 | 配文（一句话） |
|---|------|---------|---------|---------|--------------|
| 1 | **金属度/镜面双工作流** | 金属球 | `_Metalness` 0→1 或切换 specular | 转台 + 参数扫 | Metalness / Specular 双工作流 + 反射探针 |
| 2 | **程序化点阵镂空** | 一个球（TransparentCutout） | `_DotDensity` 5→30，`_DotRadius` | 相机拉近特写 + 扫密度 | Halftone 点阵镂空，纯片元生成 |
| 3 | **法线 + 视差** | 红砖方块 | `_NormalStrength` 0→1，`_ParallaxStrength` 0→0.05 | 侧视角特写 | 法线 TBN + 视差偏移 |
| 4 | **清漆 Clear Coat** | 金属球 | `_ClearCoatStrength` 0→1，`_ClearCoatSmoothness` | 转台 + 扫强度 | 清漆多层反射（车漆） |
| 5 | **自发光 + GI** | 角色/球 | `_EmissionTint`（HDR） | 扫 HDR 强度 | 自发光参与光照烘焙 |
| 6 | **遮挡贴图 AO** | 红砖方块 | `_OcclusionStrength` 0→1 | 固定机位 | AO 贴图 G 通道 |
| 7 | **光源 Cookie** | 场景 + 百叶窗 | `_MAIN_LIGHT_COOKIE` | 静帧 | 光源 Cookie 投影（百叶窗） |
| 8 | **附加光源阴影** | 场景多灯 | 多盏附加灯带阴影 | 转台 | 附加光源阴影 |
| 9 | **自发光烘焙 GI** | 场景 | `_DEBUG_BAKED_GI` | 静帧 | 自发光烘焙 GI 输出 |
| 10 | **URP Lit 对比** | 同一个球 | 左 URP Lit / 右 MyLit | 并排静帧 | 与 URP 内置 Lit 对比 |

> 如果只想发 4 张主图：选 **#1 金属、#2 点阵、#3 视差、#10 对比**。

## 三、用 MyLitShowcaseWindow 自动出片

菜单栏 `Tools > MyLit Showcase Window`。

### 转台模式（Orbit）
- 指定 **Orbit Target**（要围着转的物体）和 **Camera Transform**（主相机）
- 设旋转速度、半径、高度 → 点 Start，相机自动绕圈

### 参数扫描模式（Parameter Sweep）
- **Param Target**：拖一个带 Renderer 的物体（比如金属球）
- **Property Name**：填属性名（见下表）
- **Min / Max / Cycle**：设置扫描范围和一个周期秒数 → Start 后属性自动来回扫

**常用属性名速查**：

| 属性名 | 范围 | 说明 |
|--------|------|------|
| `_Metalness` | 0-1 | 金属度 |
| `_Smoothness` | 0-1 | 光滑度 |
| `_NormalStrength` | 0-1 | 法线强度 |
| `_ParallaxStrength` | 0-0.05 | 视差强度 |
| `_ClearCoatStrength` | 0-1 | 清漆强度 |
| `_ClearCoatSmoothness` | 0-1 | 清漆光滑度 |
| `_OcclusionStrength` | 0-1 | AO 强度 |
| `_DotDensity` | 5-30 | 点阵密度 |
| `_DotRadius` | 0.05-0.45 | 点半径 |

> 注意：像 `_NORMALMAP`、`_EMISSION`、`_OCCLUSIONMAP`、`_CLEARCOATMAP` 是 **shader 关键字**（不是 float 属性），扫参数扫不出来，需要在材质 Inspector 里手动开关。切换 Surface Type 也是。

### 录制
- 装好 **Unity Recorder**（Package Manager 里搜 "Recorder"，或已经写进 manifest）
- Window > General > Recorder > Recorder Window
- 加一个 **Movie** 源，选 Game View，30fps，1920x1080
- 点 Start Recording → 再点 Showcase 窗口 Start → 录 15-30 秒 → Stop

## 四、出图后怎么放

1. **GitHub README 顶部**：把 4 张主图放最上面（现在是纯文字，第一屏全是徽章，招募方根本看不到效果）
2. **B站**：15-30 秒原片 + 标题如"从零写一个 URP PBR Shader（含点阵镂空/清漆/视差）"
3. **社群自我介绍**：配 1 张最好的效果图 + GitHub 链接 + 一句"我想深入卡通渲染 + 性能优化"

## 五、加分项（可选）

- **对比图**：同一物体左 URP Lit / 右 MyLit，是最容易让人记住的
- **参数动图**：把参数扫描录成 GIF 放 README，比静态图强 10 倍
- **性能数据**：Frame Debugger 里截一张 Draw Call / SetPass Calls 截图，配合你性能测试背景，是独立团队最看重的
