## 四、MyLitForwardLitPass.hlsl 内部流程（Fragment）

按执行顺序：

1. **法线准备**：几何法线 + `_DOUBLE_SIDED_NORMALS` 翻转
2. **视差**：算 `viewDirTS`，偏移 uv（Part4）
3. **颜色采样 + 点阵镂空**：`CalculateDotMatrix` 覆盖 alpha（Part4）
4. **Alpha 裁切**：`TestAlphaClip`（Part2/4）
5. **法线贴图**：`_NORMALMAP` 分支，TBN 转世界（Part3）
6. **lightingInput 填充**：positionWS / normalWS / viewDir / shadowCoord / SSAO uv（Part5）
7. **烘焙 GI**：`SampleLightmap` 或 SH 兜底（Part5-二）
8. **SurfaceData 填充**：albedo / 金属或高光 / 平滑或粗糙 / 自发光 / AO / 清漆（Part3/4/5）
9. **`UniversalFragmentPBR`** 出最终颜色
